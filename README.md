# 보건실 침대 현황 (시제품)

보건실 침대 사용 현황을 보건 선생님 PC, 보건실 학생용 태블릿, 강의동 학생지원실에서 같은 상태로 보여 주는 웹 프로그램의 시제품입니다.

저장 방식은 두 가지입니다.

- **기본 (설정 없음)**: 데이터를 이 브라우저 안에 저장합니다. 실시간 반영은 **같은 PC, 같은 브라우저의 탭끼리만** 됩니다.
- **여러 기기 공유 (Supabase 연결)**: `js/config.js`에 Supabase 주소와 키를 넣으면 태블릿·PC 등 **모든 기기가 같은 현황**을 보고, 한 기기의 변경이 다른 기기에 바로 반영됩니다. 아래 "태블릿·PC 따로 시연하기"를 보세요.

## 실행

`index.html`을 더블클릭하면 Chrome이나 Edge에서 열립니다. 설치는 필요 없습니다.

- 글꼴(Pretendard)과 엑셀 명단 읽기 기능은 인터넷에서 받아 옵니다. 인터넷이 없어도 화면은 동작하고, 명단은 CSV로 올리면 됩니다.

## 시제품 계정

| 아이디 | 비밀번호 | 열리는 화면 |
| --- | --- | --- |
| `admin` | `admin1234` | 관리자 (세 화면 모두 열기, 계정·설정) |
| `nurse` | `nurse1234` | 보건 선생님 |
| `kiosk-nurse-room` | `kiosk1234` | 학생용 태블릿 |
| `support-office` | `support1234` | 학생지원실 |

- 연장용 관리번호는 `2580`입니다. 보건 선생님 화면의 **설정**에서 바꿀 수 있습니다.
- 예시 학생의 학번은 `1001`~`1040`입니다. 이름은 모두 가상입니다.

## 실시간 반영 시험하기

1. `admin`으로 로그인합니다.
2. **화면** 탭에서 세 화면을 각각 **새 탭**으로 엽니다.
3. 학생 태블릿 탭에서 `학번 직접 입력` → `1012` → 확인 → 침대를 고르고 등록합니다.
4. 보건 선생님 탭과 학생지원실 탭에 자석 이름표가 붙는 것을 확인합니다.

로그인은 탭마다 따로 유지됩니다. 그래서 한 PC에서 여러 화면을 동시에 띄울 수 있습니다.

## 태블릿·PC 따로 시연하기 (Supabase)

1. [supabase.com](https://supabase.com)에 가입하고 **New project**를 만듭니다. 지역은 **Northeast Asia (Seoul)**을 고릅니다.
2. 왼쪽 메뉴 **SQL Editor** → **New query**에 `supabase/setup.sql` 내용을 모두 붙여 넣고 **Run**을 누릅니다.
3. **Project Settings → API**(또는 상단 **Connect**)에서 **Project URL**과 **anon public 키**(또는 publishable 키)를 복사해 `js/config.js`의 `supabaseUrl`, `supabaseKey`에 넣습니다. `service_role`·secret 키는 넣지 마세요.
4. 사이트를 링크로 올립니다(예: GitHub Pages). 태블릿과 PC에서 같은 링크를 열고 각각 로그인합니다.

- 화면 오른쪽 위 연결 표시가 **연결됨**이면 공유 중입니다. 연결이 끊기면 등록 버튼이 잠깁니다.
- 두 기기에서 같은 침대를 동시에 고르면 먼저 저장된 쪽만 들어가고, 늦은 쪽에는 "방금 다른 학생이 그 침대를 골랐습니다" 알림이 뜹니다.
- `room` 이름이 같은 기기끼리 같은 현황을 봅니다. 처음 연결하면 예시 데이터로 시작합니다.
- **주의**: 시연용 설정이라 링크를 아는 사람은 누구나 데이터를 읽고 바꿀 수 있습니다. 실제 학생 이름·학번은 넣지 마세요.

## 화면별 핵심

| 화면 | 할 수 있는 일 |
| --- | --- |
| 보건 선생님 | 학번 칸에 스캔하거나 입력해 등록, 침대 카드에서 연장·퇴실, `⋯`에서 침대 이동·등록 취소, 오늘 기록, 설정(침대·연장·관리번호·알림음) |
| 학생 태블릿 | 첫 화면은 스캔 화면. 처음이면 침대 고르기, 사용 중이면 퇴실 또는 연장(관리번호) 선택. 30초 동안 입력이 없으면 처음 화면으로 돌아감 |
| 학생지원실 | 등록, 현황(실명·경과 시간), 등록 취소, 사용 기록, 사용 시간이 지나면 알림(오른쪽 위 종 버튼으로 알림음 켜고 끄기) |
| 관리자 | 세 화면 열기, 현황판, 기록, 학생 명단(구글 스프레드시트에서 불러오기, 링크를 기억해 다음에는 "다시 불러오기"), 설정(화면별 알림음)과 계정 비밀번호, 예시 데이터 초기화 |

- 침대 번호는 여학생 1~5번(2층 침대: 2번 아래층·3번 위층), 남학생 6~10번(2층 침대: 8번 아래층·9번 위층)입니다.
- 보건 선생님·학생지원실의 **침대 고르기** 창은 실제 방 배치대로 보입니다. 침대가 없는 칸은 침대 반 칸 너비의 통로로 비워 둡니다. 배치 위치는 `js/store.js`의 `DEFAULT_BEDS`에 있는 `row`(줄)와 `col`(칸) 값입니다. 설정에서 침대의 구역을 바꾸거나 새 침대를 넣으면 그 구역은 현황판 순서대로 2열로 보입니다.
- 침대 카드의 **연장** 버튼을 누르면 확인 창이 먼저 뜹니다. 끝나는 시각과 연장 횟수가 어떻게 바뀌는지 보여 줍니다.
- 사용 시간은 등록한 뒤 **다음 정각(한국 표준시)까지**입니다. 예: 14:20에 등록하면 15:00까지, 15:00에 등록하면 16:00까지. 연장하면 끝나는 시각에 연장 시간(기본 60분)이 더해집니다.
- 끝나는 시각이 지나면 카드가 빨간색으로 바뀝니다. 이중 테두리, 시계 아이콘, "사용 시간 초과"(연장 뒤에는 "연장 시간 초과") 문구가 함께 붙습니다.
- 학생 태블릿에서 로그아웃하려면 왼쪽 위 **보건실** 글자를 2초 동안 길게 누릅니다. 보건 선생님이나 관리자 비밀번호가 필요합니다.
- 학생 태블릿 오른쪽 위 **전체 화면** 버튼을 누르면 주소창 없이 화면 전체를 씁니다. 한 번 켜 두면 새로 고침 등으로 풀려도 다음 터치 때 다시 전체 화면이 됩니다. 끄려면 **보건실** 글자를 2초 길게 눌러 비밀번호를 넣고 **전체 화면 끝내기**를 누릅니다. (iPhone은 브라우저가 전체 화면을 지원하지 않아 버튼이 보이지 않습니다.)

## 색 바꾸기

모든 색은 `css/app.css` 맨 위 `:root { ... }` 블록에 모여 있습니다. 그 값만 바꾸면 모든 화면에 적용됩니다.

| 변수 | 쓰이는 곳 |
| --- | --- |
| `--frame` | 상단 바와 바깥 테두리 |
| `--board` | 현황판 바탕 |
| `--magnet` | 사용 중 이름표, 선택된 탭, 강조 |
| `--over` | 사용 시간 초과 (빨간 이름표) |
| `--live` | 연결 상태 점 |

## 파일 구조

```
index.html        진입점
css/app.css       스타일 (색은 맨 위 :root)
js/config.js      여러 기기 공유 설정 (Supabase 주소·키, 비우면 브라우저 안에서만)
js/store.js       데이터: 브라우저 저장 또는 Supabase 공유
supabase/setup.sql  Supabase에서 한 번 실행하는 표·권한·실시간 설정
js/ui.js          공통 도구 (시간 형식, 대화상자, 알림, CSV)
js/board.js       침대 현황판과 등록·연장·퇴실·이동·취소
js/views.js       사용 기록, 설정, 학생 명단
js/kiosk.js       학생용 태블릿
js/screens.js     로그인, 보건 선생님, 학생지원실, 관리자
js/app.js         로그인 상태와 주소(#/nurse 등)에 따라 화면 열기
PRODUCT.md        제품 정보 (디자인 작업용)
```

## 2단계: 실제 운영

요청하면 PRD 권장안(React + TypeScript + Vite + Supabase, 서울 리전)으로 옮깁니다. 그러면 세 기기 사이 실시간 공유, 진짜 로그인과 권한, 서버에서의 관리번호 확인, 기록 보관이 됩니다. 화면 구성과 흐름은 이 시제품을 그대로 따릅니다.
