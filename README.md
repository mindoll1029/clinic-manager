# 보건실 침대 현황 (시제품)

보건실 침대 사용 현황을 보건 선생님 PC, 보건실 학생용 태블릿, 강의동 학생지원실에서 같은 상태로 보여 주는 웹 프로그램의 시제품입니다.

저장 방식은 두 가지입니다.

- **기본 (설정 없음)**: 데이터를 이 브라우저 안에 저장합니다. 실시간 반영은 **같은 PC, 같은 브라우저의 탭끼리만** 됩니다.
- **여러 기기 공유 (Supabase 연결)**: `js/config.js`에 Supabase 주소와 키를 넣으면 태블릿·PC 등 **모든 기기가 같은 현황**을 보고, 한 기기의 변경이 다른 기기에 바로 반영됩니다. 아래 "태블릿·PC 따로 시연하기"를 보세요.

## 실행

`index.html`을 더블클릭하면 Chrome이나 Edge에서 열립니다. 설치는 필요 없습니다.

- 글꼴(Pretendard)과 엑셀 명단 읽기 기능은 인터넷에서 받아 옵니다. 인터넷이 없어도 화면은 동작하고, 명단은 CSV로 올리면 됩니다.

## 시제품 계정

| 아이디 | 비밀번호 | 열리는 화면 |
| --- | --- | --- |
| `admin` | `admin1234` | 관리자 (모든 화면 열기, 계정·설정) |
| `nurse` | `nurse1234` | 보건 선생님 |
| `kiosk-nurse-room` | `kiosk1234` | 보건실 학생용 태블릿 |
| `kiosk-support-office` | `office1234` | 학생지원실 학생용 태블릿 (등록·퇴실, 연장 없음) |
| `support-office` | `support1234` | 학생지원실 |
| `nurse-assistant` | `assist1234` | 학생지원실 (보건 조교. 학생지원실과 같은 화면이지만 퇴실 처리도 근무 시간과 상관없이 언제나 됩니다. 기록에는 "보건 조교"로 남습니다) |

- 연장은 **보건 선생님·보건 조교·학지실 PC** 화면에서만 하고, 연장할 때마다 **연장 암호**를 넣습니다. 학생용 태블릿과 관리자 현황판에는 연장 버튼이 없습니다.
- 연장 암호는 처음에는 없습니다. 보건 선생님 화면(또는 관리자)의 **설정 → 연장 암호**에서 정하기 전에는 아무도 연장할 수 없습니다.
- 예시 학생의 학번은 `1001`~`1040`입니다. 이름은 모두 가상입니다.

## 실시간 반영 시험하기

1. `admin`으로 로그인합니다.
2. **화면** 탭에서 각 화면을 **새 탭**으로 엽니다.
3. 학생 태블릿 탭에서 `학번 입력` → `1012` → 확인 → 침대를 고르고 등록합니다.
4. 보건 선생님 탭과 학생지원실 탭에 자석 이름표가 붙는 것을 확인합니다.

- 태블릿 등록은 보건 선생님 근무 시간에만 됩니다. 근무 시간 밖에 시험하려면 보건 선생님 화면 **설정 → 근무 일정 → 날짜별 변경**에 오늘 시간을 넣으세요.

로그인은 탭마다 따로 유지됩니다. 그래서 한 PC에서 여러 화면을 동시에 띄울 수 있습니다.

## 태블릿·PC 따로 시연하기 (Supabase)

1. [supabase.com](https://supabase.com)에 가입하고 **New project**를 만듭니다. 지역은 **Northeast Asia (Seoul)**을 고릅니다.
2. 왼쪽 메뉴 **SQL Editor** → **New query**에 `supabase/setup.sql` 내용을 모두 붙여 넣고 **Run**을 누릅니다.
3. **Project Settings → API**(또는 상단 **Connect**)에서 **Project URL**과 **anon public 키**(또는 publishable 키)를 복사해 `js/config.js`의 `supabaseUrl`, `supabaseKey`에 넣습니다. `service_role`·secret 키는 넣지 마세요.
4. 사이트를 링크로 올립니다(예: GitHub Pages). 태블릿과 PC에서 같은 링크를 열고 각각 로그인합니다.

- 화면 오른쪽 위 연결 표시가 **연결됨**이면 공유 중입니다. 연결이 끊기면 등록 버튼이 잠깁니다.
- 두 기기에서 같은 침대를 동시에 고르면 먼저 저장된 쪽만 들어가고, 늦은 쪽에는 "방금 다른 학생이 그 침대를 골랐습니다" 알림이 뜹니다.
- `room` 이름이 같은 기기끼리 같은 현황을 봅니다. 처음 연결하면 예시 데이터로 시작합니다.
- **주의**: 시연용 설정이라 링크를 아는 사람은 누구나 데이터를 읽고 바꿀 수 있습니다. 실제 학생 이름·학번은 넣지 마세요.

## 화면별 핵심

| 화면 | 할 수 있는 일 |
| --- | --- |
| 보건 선생님 | 학번 칸에 스캔하거나 입력해 등록, 침대 카드에서 연장·퇴실, `⋯`에서 침대 이동·등록 취소, 오늘 기록, 설정(근무 일정·침대·연장 시간·알림음·연장 암호·구글 시트 연동·잔디 알림) |
| 보건실 학생용 태블릿 | 학생증 스캔 또는 **학번 입력**. 사용 중이 아니면 침대 현황표에서 골라 등록(근무 시간에만). 사용 중이면 바로 "퇴실을 요청하겠습니까?"(언제나). 연장 없음. 30초 동안 입력이 없으면 처음 화면으로 돌아감. 근무 시간 밖: 현황과 퇴실 요청만 ("등록은 학생지원실에서 하세요" 안내) |
| 학생지원실 학생용 태블릿 | 언제나 열려 있음. 학생증 스캔 또는 **학번 입력**. 사용 중이 아니면 침대 현황표에서 골라 등록(현황판·기록에는 "학지실 태블릿"으로 표시). 사용 중(퇴실 중 포함)이면 "퇴실하겠습니까?" → **예**를 누르면 바로 퇴실. 연장 없음 |
| 학생지원실 (보건 조교도 같은 화면) | 등록, **연장**(언제나), **퇴실 확인**(언제나), 현황(실명·경과 시간), 등록 취소, 사용 기록, 사용 시간이 지나면 알림(오른쪽 위 종 버튼으로 알림음 켜고 끄기). 보건 선생님 퇴근 10분 전부터(근무 시간 밖에는 언제나) 퇴실 처리. 보건 조교는 근무 시간과 상관없이 언제나 퇴실 처리 |
| 관리자 | 모든 화면 열기, 현황판(연장 버튼 없음), 기록, 학생 명단(구글 스프레드시트에서 불러오기, 링크를 기억해 다음에는 "다시 불러오기"), 설정(화면별 알림음, 연장 암호, 구글 시트 연동, 잔디 알림)과 계정 비밀번호, 예시 데이터 초기화 |

- **퇴실 요청 → 학생지원실에서 퇴실**: 보건실 태블릿에서는 바로 퇴실하지 않고 퇴실을 **요청**합니다. 학생지원실에서 퇴실이 끝납니다.
  1. 학생이 보건실 태블릿에서 학생증을 스캔하거나 학번을 입력 → "퇴실을 요청하겠습니까?" → **예**.
  2. **예**를 누르면 바로 모든 화면에 **퇴실 중**으로 바뀌고, 태블릿에 "학지실로 이동하세요" 화면이 5초 동안 나온 뒤 처음 화면으로 돌아갑니다.
  3. 퇴실 중인 침대는 어두운 이름표로 보이고, 큰 숫자는 퇴실을 요청한 뒤 지난 시간(분)입니다. 침대는 퇴실 확인 전까지 "사용 중"으로 남습니다.
  4. 학생이 학생지원실에 오면 **학생지원실 태블릿**에서 학생증을 스캔하거나 학번을 입력 → "퇴실하겠습니까?" → **예**로 퇴실이 끝납니다. 학생지원실 PC에서 학생증을 학번 칸에 스캔하거나 카드의 **퇴실 확인**을 눌러도 됩니다(창에서 이름·학번 확인). 보건 선생님 화면에서도 할 수 있습니다.
  5. 퇴실 중으로 **10분**이 지나도 확인되지 않으면 카드에 빨간 테두리와 "퇴실 확인 안 됨"이 붙고, **잔디**로 한 번 알립니다(아래 "잔디 알림").
  - 퇴실 중에는 사용 시간 초과 알림이 울리지 않고, 연장할 수 없습니다.
  - 학생지원실 태블릿에서 사용 중인 학생이 "퇴실하겠습니까?"에 예를 누르면 퇴실 요청 없이 바로 퇴실됩니다(학생이 학생지원실에 와 있으므로).
- **구글 시트 연동 (연장 기록)**: 연장할 때마다 구글 시트 '연장 기록' 탭에 한 줄씩 남습니다. 칸: 기록 시각, 날짜, 연장 시각, 침대, 학번, 이름, 반, 그룹, 연장한 곳(보건 선생님·보건 조교·학지실 PC), 연장 횟수, 이전·새 끝나는 시각, 연장 시간(분), 기록 번호.
  - 처음 한 번 보건 선생님 화면(또는 관리자)의 **설정 → 구글 시트 연동**에서 순서대로 합니다.
    1. **새 구글 시트 만들기** 버튼 → 학교 구글 계정으로 새 시트가 열립니다. 이름은 자유롭게 정합니다.
    2. 시트 메뉴 **확장 프로그램 → Apps Script** → 원래 내용을 지우고 설정의 **코드 복사**로 복사한 코드를 붙여 넣고 저장합니다.
    3. **배포 → 새 배포 → 웹 앱**, 실행: **나**(Me), 액세스: **모든 사용자**(Anyone) → 배포 → 권한 허용(계정 선택 → "고급" → "이동" → 허용) → **웹 앱 URL** 복사.
    4. 설정의 **웹 앱 주소** 칸에 붙여 넣고 **연동 테스트** → 시트에 '연장 기록' 탭과 제목 줄이 생기면 **저장**.
  - 학교(Google Workspace) 계정에서 액세스에 "모든 사용자"가 없으면 학교 관리자가 막아 둔 것입니다. 관리자에게 허용을 요청하거나 개인 구글 계정으로 시트를 만드세요.
  - Apps Script 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다(주소는 그대로).
  - 시트로 보내지 못하면 1분마다 다시 보내고(최대 5번), 그래도 안 되면 설정에 "보내지 못한 연장 기록 N건"과 **다시 보내기**가 보입니다. 같은 기록은 시트에 두 번 쓰지 않습니다.
  - 시트로는 **Netlify 주소(…netlify.app)로 연 화면**에서만 보냅니다(Netlify 서버 함수 `netlify/functions/sheet.mjs`를 거칩니다). 열려 있는 화면 중 한 곳이 보냅니다.
  - 시트에는 학생 이름·학번이 남습니다. 시트 공유 범위를 보건실·학지실 담당자로 제한하세요.
- **잔디 알림**: 보건 선생님 화면(또는 관리자)의 **설정 → 잔디 알림**에 잔디 웹훅 주소를 넣고 저장합니다.
  - 주소 받기: 알림을 받을 잔디 대화방 → 오른쪽 위 **연동(커넥트)** → **Incoming Webhook** 추가 → 나오는 `https://wh.jandi.com/connect-api/webhook/…` 주소를 복사합니다.
  - **테스트 보내기**로 잔디 대화방에 메시지가 오는지 확인합니다(저장 전 주소로도 시험할 수 있습니다).
  - 메시지에는 침대, 학생 이름·학번·반, 퇴실 요청 시각이 들어갑니다. 열려 있는 화면(PC·태블릿)이 여러 개여도 한 번만 보냅니다. 보내지 못하면 1분마다 최대 3번까지 다시 보냅니다.
  - 잔디는 **Netlify 주소(…netlify.app)로 연 화면**에서만 보낼 수 있습니다. Netlify 서버 함수(`netlify/functions/jandi.mjs`)를 거쳐 보내기 때문입니다. 파일로 연 화면이나 GitHub Pages 주소에서는 보내지 않습니다.
  - 알림은 열려 있는 화면이 있어야 보냅니다. 보건실 태블릿이나 학생지원실 PC 중 하나는 켜 두세요.

- **근무 일정**: 보건 선생님 화면(또는 관리자)의 **설정 → 근무 일정**에서 요일별 출퇴근 시각과 날짜별 변경(연차·조퇴)을 정합니다. 기본은 월~금 08:30~17:30입니다.
  - 근무 시간: 보건실 태블릿에서 등록·퇴실 요청. 학생지원실 PC는 등록·연장·등록 취소·퇴실 확인.
  - 퇴근 10분 전부터: 학생지원실 카드에 퇴실 버튼이 나타납니다(보건실 태블릿도 퇴근 시각까지는 그대로).
  - 근무 시간 밖: 보건실 태블릿은 현황과 퇴실 요청만, 등록은 학생지원실(태블릿·PC)에서.
  - 학생지원실 태블릿의 등록·퇴실, 보건실 태블릿의 퇴실 요청, 학생지원실 PC의 연장·퇴실 확인은 근무 시간과 상관없이 언제나 됩니다.
  - 보건 조교 계정은 위 시간과 상관없이 언제나 퇴실 처리도 할 수 있습니다.
  - 시각은 각 기기의 시계를 따릅니다. 태블릿·PC 시계가 한국 시간에 맞아 있어야 합니다.
- **사용 시간 초과 알림**: 보건 선생님·학생지원실(보건 조교 포함) 화면에서 침대 사용 시간이 지나는 순간 화면 오른쪽 아래에 빨간 알림이 6초 동안 뜹니다. 현황판뿐 아니라 사용 기록·설정 탭을 보고 있어도 뜹니다. 관리자 화면과 학생 태블릿에는 뜨지 않습니다.
  - 알림음은 위쪽 종 버튼이나 설정의 체크 상자로 켜고 끕니다. 알림 글과 빨간 카드는 늘 보입니다.
  - **알림음 테스트** 버튼(위쪽 바의 스피커 버튼, 설정의 "사용 시간과 연장")을 누르면 같은 자리에 "테스트" 알림이 뜨고 알림음이 한 번 울립니다. 종 버튼을 누르거나 설정을 저장할 때는 테스트 알림이 뜨지 않습니다.
  - 같은 순간에 여러 명이 시간을 넘기면 알림 하나에 학생 목록을 모아서 보여 주고(5명 넘으면 "외 N명"), 알림음도 한 번만 울립니다.
  - 새로 고침한 뒤 화면을 한 번도 누르지 않으면 브라우저가 소리를 막을 수 있습니다. 화면을 연 뒤 아무 곳이나 한 번 눌러 두세요.
- **윈도우 알림**: 화면을 보고 있지 않을 때(다른 탭, 창 최소화, 다른 프로그램 사용 중)는 초과 알림이 윈도우 알림으로도 뜹니다. 알림을 누르면 화면으로 돌아옵니다. 탭이나 브라우저를 닫으면 오지 않습니다.
  - **링크(https://...)로 연 화면에서만** 됩니다. `index.html`을 파일로 열면 위쪽에 "파일로 연 화면이라 윈도우 알림을 쓸 수 없습니다" 안내가 뜹니다.
  - PC마다 처음 한 번 위쪽 안내의 **알림 허용**(또는 알림음 테스트)을 누르고 브라우저 창에서 "허용"을 고릅니다. 알림음 테스트를 누르면 윈도우 알림도 함께 와서 확인할 수 있습니다.
  - 윈도우 **설정 → 시스템 → 알림**에서 브라우저(Edge·Chrome) 알림이 켜져 있고 "방해 금지"가 꺼져 있어야 합니다.
  - 오래 안 본 탭을 재우는 기능에 이 사이트를 예외로 넣어 두세요. Edge: **설정 → 시스템 및 성능 → "이 사이트를 절전 모드로 전환하지 않음"**에 추가. Chrome: **설정 → 성능 → "항상 활성 상태로 유지할 사이트"**에 추가.
- 침대 번호는 여학생 1~5번(2층 침대: 2번 아래층·3번 위층), 남학생 6~10번(2층 침대: 8번 아래층·9번 위층)입니다.
- 보건 선생님·학생지원실의 **침대 고르기** 창은 실제 방 배치대로 보입니다. 침대가 없는 칸은 침대 반 칸 너비의 통로로 비워 둡니다. 배치 위치는 `js/store.js`의 `DEFAULT_BEDS`에 있는 `row`(줄)와 `col`(칸) 값입니다. 설정에서 침대의 구역을 바꾸거나 새 침대를 넣으면 그 구역은 현황판 순서대로 2열로 보입니다.
- 침대 카드의 **연장** 버튼을 누르면 확인 창이 먼저 뜹니다. 끝나는 시각과 연장 횟수가 어떻게 바뀌는지 보여 주고, **연장 암호**를 넣어야 연장됩니다.
- 연장 횟수에는 제한이 없습니다.
- 사용 시간은 등록한 뒤 **다음 정각(한국 표준시)까지**입니다. 예: 14:20에 등록하면 15:00까지, 15:00에 등록하면 16:00까지. 연장하면 끝나는 시각에 연장 시간(기본 60분)이 더해집니다.
- 끝나는 시각이 지나면 카드가 빨간색으로 바뀝니다. 이중 테두리, 시계 아이콘, "사용 시간 초과"(연장 뒤에는 "연장 시간 초과") 문구가 함께 붙습니다.
- 학생 태블릿에서 로그아웃하려면 왼쪽 위 **보건실** 글자를 2초 동안 길게 누릅니다. 보건 선생님이나 관리자 비밀번호가 필요합니다. 학생지원실 태블릿은 **학생지원실** 글자를 길게 누르고, 학생지원실 비밀번호로도 됩니다.
- 학생 태블릿 오른쪽 위 **전체 화면** 버튼을 누르면 주소창 없이 화면 전체를 씁니다. 전체 화면은 이 버튼으로만 켜집니다. 끄려면 **보건실** 글자를 2초 길게 눌러 비밀번호를 넣고 **전체 화면 끝내기**를 누릅니다. (iPhone은 브라우저가 전체 화면을 지원하지 않아 버튼이 보이지 않습니다.)

## 색 바꾸기

모든 색은 `css/app.css` 맨 위 `:root { ... }` 블록에 모여 있습니다. 그 값만 바꾸면 모든 화면에 적용됩니다.

| 변수 | 쓰이는 곳 |
| --- | --- |
| `--frame` | 상단 바와 바깥 테두리 |
| `--board` | 현황판 바탕 |
| `--magnet` | 사용 중 이름표, 선택된 탭, 강조 |
| `--over` | 사용 시간 초과 (빨간 이름표) |
| `--live` | 연결 상태 점 |

```

```

## 2단계: 실제 운영

요청하면 PRD 권장안(React + TypeScript + Vite + Supabase, 서울 리전)으로 옮깁니다. 그러면 세 기기 사이 실시간 공유, 진짜 로그인과 권한, 서버에서의 권한 확인, 기록 보관이 됩니다. 화면 구성과 흐름은 이 시제품을 그대로 따릅니다.
